# Preguntas frecuentes

**¿Tengo que cambiar mis cámaras o grabadores?**
No. VIGÍA trabaja con cámaras IP y grabadores de los principales fabricantes (Hikvision, Bosch, Uniview y equipos ONVIF). Algunas funciones dependen del encuadre: para leer matrículas, la cámara tiene que ver la placa con suficiente resolución.

**¿Sale alguna imagen a internet?**
No. Imágenes, vectores, modelos de IA y chat corren en el servidor municipal. La opción de usar un modelo en la nube existe, pero está desactivada por defecto y solo se activa de forma expresa y auditada.

**¿Reconoce caras?**
No. El reconocimiento facial está excluido del producto por diseño.

**¿Qué hardware hace falta?**
Un ordenador con tarjeta gráfica actual en la red de vídeo. Hay perfiles para equipos solo con CPU, con una GPU de 4 GB, de 16 GB o con dos GPU. Con más GPU se analizan más cámaras a la vez y se indexa más rápido.

**¿Cuánto tarda en instalarse?**
El objetivo de diseño es una máquina limpia operativa en menos de un día. La calibración con las cámaras reales y la formación llevan unas semanas más.

**¿Qué pasa si algo falla?**
Un supervisor comprueba cada servicio haciendo trabajo real, reinicia solo el que falla y, si se repite, lo aísla y avisa. El sistema arranca solo tras un corte de luz.

**¿Puedo consultar la titularidad de un vehículo?**
La integración con la DGT está preparada y se activa cuando el organismo tiene el convenio de acceso. Mientras tanto, el sistema lo dice claramente y no inventa datos.

**¿Por qué no se publica el código?**
Porque protege datos personales de alto riesgo de un servicio público y su superficie de ataque no debe ser pública. Este repositorio explica cómo funciona sin exponer nada. Para una evaluación técnica en profundidad se puede pedir una demo o una revisión bajo acuerdo de confidencialidad.

**¿Sirve para empresas o solo para ayuntamientos?**
Para ambos: polígonos industriales, urbanizaciones, aparcamientos o recintos privados. Se activan solo los módulos necesarios.
