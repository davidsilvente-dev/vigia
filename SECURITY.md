# Seguridad

## Qué contiene (y qué no) este repositorio

Este repositorio es **solo documentación**. No contiene código ejecutable, configuraciones, direcciones IP, credenciales, inventarios de cámaras, ubicaciones, matrículas ni imágenes de ninguna instalación.

Si encuentras en este repositorio algo que parezca un dato sensible de una instalación real, avísanos para retirarlo de inmediato.

## Cómo informar de una vulnerabilidad

Si crees haber encontrado un problema de seguridad en VIGÍA o en esta documentación:

1. **No abras una issue pública.**
2. Escribe a través de <https://davidsilvente.com/#contacto> indicando «Seguridad VIGÍA» en el asunto.
3. Incluye una descripción del problema y, si es posible, cómo reproducirlo.

Respondemos en un plazo máximo de 5 días laborables.

**No** se autoriza ninguna prueba contra instalaciones en producción.
